## 🌟 Overview

Welcome to the official repository for **Karthik T's Cinematic Personal Portfolio**. 

Built with an editorial luxury dark aesthetic, golden illumination, and smooth kinetic interactions, this web application highlights core competencies in **Data Analytics, Business Intelligence, Data Engineering Pipelines, and AI/ML**.

### 🎨 Key Visual Features
- **Cinematic Dark Luxury Aesthetic**: Pure pitch-black canvas (`#000000`) paired with regal metallic gold accents (`#D4AF37`, `#8C6D4F`, `#F7E7C4`).
- **Kinetic Typography**: Large-scale editorial typography utilizing **Bebas Neue**, **Montserrat**, and **Herr Von Muellerhoff** monoline signatures.
- **Dynamic 3D Tilt Card**: Interactive mouse-tracking holographic portrait frame with live gold spark embers and laser border pulses.
- **Interactive Stacking Case Studies (`ScrollStack`)**: Smooth sticky card scroll stacking featuring deep dive metrics, interactive tabbed dashboard previews, and modal inspect views.
- **Lenis Smooth Scrolling**: Ultra-fluid inertia scrolling across all desktop and mobile viewports.

## 🚀 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18.0.0 or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/karthikkarthi18012008-star/E-Portfolio..git
   cd E-Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
   The production bundle will be generated in the `dist/` directory.
